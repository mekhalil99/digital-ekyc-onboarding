# digital-ekyc-onboarding
 
**Purpose:** A business analysis case study for digital account opening at a fictional Egyptian bank, Nile Bank. It covers the as-is branch process, the pain points, the requirements and their priority, and the measures for judging success. All people and data are synthetic.
 
## What's in the repo
 
| Folder | Contents |
|---|---|
| `01-brief-and-scope` | Project brief: problem, scope, stakeholders, assumptions, KPIs and evidence |
| `02-process-maps-bpmn` | As-is process map (BPMN), step table and pain-point register |
| `03-requirements` | Backlog, MoSCoW and RICE ranking |
